# DAS API Reference

## GetInstanceGroupInspectReportList
- Endpoint: `das.cn-hangzhou.aliyuncs.com`
- Version: `2020-01-16`
- Required parameters: `StartTime`, `EndTime`
- Returns: List of report IDs

## GetInstanceGroupInspectReportDetail  
- Endpoint: `das.cn-hangzhou.aliyuncs.com`
- Version: `2020-01-16`
- Required parameters: `ReportId`
- Returns: Full report content in markdown format
